# Party mode

Party mode is a purely cosmetic layer on top of Ais. It adds graphical effects that respond to your annotation input, and a tally of how much effort you have put into annotation and testing. We added it because we could do with some extra stimulation during long annotation sessions. 

Turn on party mode with the ✨ sparkle button at the top-left of the window, next to the menu bar. **Party mode is off by default**. When it is on, a party mode menu appears in the menu bar with its settings. It does not add much computational load, but if you are remote-viewing Ais you will probably want to keep it off because it does slow down streaming.

## Tracking annotation effort
With party mode on, Ais keeps track of how much effort you spent annotating training data and training and testing models. Separate scores are kept for every feature you work on: drawing with the brush, placing boxes, training a model, or doing inference earn points for that feature. With enough points, you level up - and importantly, you can share that great achievement on Bluesky.
